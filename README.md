# Mini-trello

This project provides a simple web page to track your daily tasks. It helps you organize your routine by dividing your activities into three main categories: **To Do**, **In Progress**, and **Finished**.

1. **Clone the repository:**
   ```
   git clone https://github.com/Luizrattacaso/mini-trello.git
   cd mini-trello
   ```
   
2. **Install the dependencies**
   ```
   npm install
   ```
3. **Run the local environment**
   ```
   cd src && npm run dev
   ```
4. **Open the web application in your browser pasting**
   ```
   http://localhost:5173/
   ```
